应用更新

  1. 点下方按钮，下载 pending.patch.json（本次差异清单）。
  2. 把它放进项目的 data/ 目录（仅用于缩小下载范围，也可以跳过）。
  3. 在项目根目录执行 python tools/sync.py：拉取最新官方数据 → 只下载新图 → 重建全部数据集。
  4. 回到前台刷新页面即可（顶栏版本号会更新，新英雄自动归位到对应 heroId 分组）。
python tools/sync.py

  1. 本页点「检查更新」，确认官方新增了什么。

    3. 
      
  3. 执行 python tools/sync.py：自动拉官方最新 skins.js / hero_list.js，旧文件归档到 data/raw/archive/，并重建数据集。
    4. 
      
  4. 再执行 python tools/download_images.py --workers 16 只补新图（已有图片自动跳过）。
    5. 
      
  5. 刷新前台：新英雄自动归位到对应 heroId 分组，新皮肤会出现在图鉴、统计与拼图里。
